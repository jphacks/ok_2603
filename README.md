# 沖縄の選挙を知り、自分で考えるアプリ（仮称）

## 製品概要

沖縄県内の若者が政治・選挙を知るきっかけをつくり、投票先を考えるときに公式情報を確認・比較できるよう支援するブラウザーアプリ。

用語解説やクイズで政治・選挙を知り、自分の地域の選挙を選び、「子育て支援」「交通」などの関心語で候補者の公約を比較する。候補者の順位付けや推薦はせず、公式情報と出典を示して利用者自身の判断を支援する。

## 初版の方針

- 対象は沖縄県内の市町村選挙。初版で実際に扱う地域・選挙は、公式情報の入手可能性を調べて決める。
- 選挙日・選挙の種類・候補者などは選挙管理委員会等の公式情報で確認する。
- 公約は候補者・政党の公式発信、または選挙管理委員会等が公開する選挙公報を出典とする。
- 関心語で公約を検索し、該当箇所、分かりやすい要約、原文へのリンク、確認日を表示する。
- 公約の具体性は項目別に記載の有無を示し、実現可能性や候補者の優劣を採点しない。
- 用語解説・クイズは公的な根拠を示し、政治的賛否を誘導しない。
- 初版では相性診断、点数化、候補者の推薦、年齢・職業等のプロフィール入力を行わない。
- 過去の活動や年代別投票率は、公式データを確認でき、MVP完成後に時間がある場合の追加候補とする。投票先の年代別集計は行わない。
- 公式情報以外は公約情報の出典として使用しない。公約が見つからない場合は「公式情報を確認できず」と表示する。

### 特長

- 政治・選挙を知る入口から、投票前に公式情報を比較するところまでをつなぐ。
- 属性による診断ではなく、利用者自身が関心語で公約を探して比べられる。
- 要約と原文、情報の発信者、確認日を併記し、利用者が自分で確かめられる。

## 開発技術

- フロントエンド: React / TypeScript / Vite
- 対象デバイス: PC・スマートフォンのブラウザー
- 公約データの収集・更新方法、検索実装、保存方式は設計中。公式情報の利用条件と更新可能性を確認して決める。

## 開発環境のセットアップ

### 必要なもの

- Node.js 20.19 以上、または Node.js 22.12 以上
- npm
- Git

### 初回セットアップ

リポジトリをまだ取得していない場合:

```bash
git clone https://github.com/jphacks/ok_2603.git
cd ok_2603
```

プロジェクトのフォルダーで最新の変更を取り込みます。

```bash
git pull origin main
```

依存パッケージをロックファイルどおりにインストールし、開発サーバーを起動します。

```bash
npm ci
npm run dev
```

ターミナルに表示されたURL（通常は `http://localhost:5173/`）をブラウザーで開いてください。開発サーバーを止めるには、起動中のターミナルで `Ctrl+C` を押します。

Node.jsは事前に各自のPCへインストールしてください。`git pull` はコードを取得する操作で、Node.jsやnpmパッケージのインストール、アプリの起動は行いません。

### ビルドとコード確認

```bash
npm run build
```

機能を変更する場合は `main` に直接コミットせず、作業ブランチを作成してPull Requestで共有してください。
