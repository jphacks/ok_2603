# Focus Town（仮称）

## 製品概要

### 背景（製品開発のきっかけ、課題等）

勉強や作業を始めても集中が続きにくく、継続した努力を実感しづらい課題を、タイマーと街づくりの達成感で支援する。

### 製品説明（具体的な製品の説明）

勉強や作業の成果を街の成長として残す、PC・スマートフォン向けブラウザーアプリ。25分の作業を完了すると街が発展し、住民からねぎらいのメッセージが届く。中断しても、それまでの実績や街の成長は失われず、自分のペースで戻ってこられる。

### 特長

#### 1. ポモドーロ・タイマーと街づくりを掛け合わせる

#### 2. 中断を失敗扱いせず、これまでの努力を保って再開できる

#### 3. アカウント不要で、作業実績を端末内に保存する

### 開発テーマ「X-Tech 2026 / Full Stack Hackers」との接続

- **掛け算（X-Tech）**: 学習タイマーと街づくりを組み合わせ、目に見えにくい学習の積み重ねを街の変化にする。
- **着目する課題**: 中断そのものをなくすのではなく、中断を失敗と感じて作業に戻りにくくなる場面に着目する。過去の努力を守り、再開しやすい体験を目指す。これは検証前の仮説である。
- **人が主役の体験**: 街の成長は利用者が実際に作業を完了した結果とする。AIが努力や成果を代わりに作るのではなく、住民の言葉や街の表現はチームが考えて用意する。
- **縦方向の実装**: 画面操作、タイマー、作業状態、端末内保存、街の表示までを一連の体験として完成させる。初版でハードウェアやサーバーまで実装するという意味ではない。
- **Real Impactの仮説**: 努力を目に見える形にすることで、学習者が次の作業にも戻りやすくなるかを試作品で確かめる。効果が確認済みであるとは主張しない。

### 解決したいこと

勉強を始めても集中が続かず、継続した努力を実感しにくいこと。作業の完了を街の成長として可視化し、小さな達成感を積み重ねる。

### 今後の展望

まずは対象となる学習者に試してもらい、街の成長が次の作業を始める動機になるかを確認する。その結果を踏まえて、成長表現や利用者が時間を調整する機能を検討する。

### 注力すること

- 中断しても、それまでに完了した作業や街の成長を失わせない。
- 中断の演出は街を罰したり壊したりするものではなく、戻るための合図として表現する。
- カメラ・ログイン・外部AI連携を使わず、個人の作業記録を端末内にとどめる。
- 発表では、課題・解決策・実際に動くデモを短時間で一貫して伝える。

## 開発環境のセットアップ

### 必要なもの

- Node.js 20.19 以上、または Node.js 22.12 以上
- npm
- Git

### 初回セットアップ

リポジトリをまだ取得していない場合:

```bash
git clone https://github.com/jphacks/ok_2603.git
cd ok_2603
```

開発環境のPull Requestが `main` に取り込まれた後、リポジトリを取得済みのメンバーはプロジェクトのフォルダーで最新の変更を取り込みます。

```bash
git pull origin main
```

依存パッケージをロックファイルどおりにインストールし、開発サーバーを起動します。

```bash
npm ci
npm run dev
```

ターミナルに表示されたURL（通常は `http://localhost:5173/`）をブラウザーで開いてください。開発サーバーを止めるには、起動中のターミナルで `Ctrl+C` を押します。

Pull Requestが `main` に取り込まれる前に試す場合は、次のように環境構築ブランチを取得してください。

```bash
git fetch origin
git switch --track origin/setup/react-vite
npm ci
npm run dev
```

Node.jsは事前に各自のPCへインストールしてください。`git pull` はコードを取得する操作で、Node.jsやnpmパッケージのインストール、アプリの起動は行いません。

### ビルドとコード確認

```bash
npm run build
```

機能を変更する場合は `main` に直接コミットせず、作業ブランチを作成してPull Requestで共有してください。
