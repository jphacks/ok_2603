# Focus Town（仮称）

## 製品概要

### 背景（製品開発のきっかけ、課題等）

勉強や作業を始めても集中が続きにくく、継続した努力を実感しづらい課題を、タイマーと街づくりの達成感で支援する。

### 製品説明（具体的な製品の説明）

25分の作業と5分の休憩を管理する、PC・スマートフォン向けブラウザーアプリ。作業を完了すると街が発展し、住民からねぎらいのメッセージが届く。作業中に画面を離れた場合はタイマーを止め、街に災害の演出を表示する。街の成長や完了済みの実績は失われない。

### 特長

#### 1. 作業時間に応じて街が発展する

#### 2. 作業完了時に住民からメッセージが届く

#### 3. アカウントやカメラを使わず、街の状態を端末内に保存する

### 解決できること

学習時間を街の成長として可視化し、小さな達成感を積み重ねて勉強の継続を助ける。

### 今後の展望

成長する建物や街の演出を増やす。初版の利用状況を確認したうえで、利用者が時間を調整する機能や、住民メッセージの個別化を検討する。

### 注力したこと（こだわり等）

- 中断時も、それまでの街の成長や完了実績を失わせない。
- カメラ・ログイン・外部AI連携を初版の必須機能にせず、すぐ試せる形を目指す。
