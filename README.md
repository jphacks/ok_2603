# 選挙情報Webアプリ（名称未定）

沖縄県内の選挙・候補者の閲覧と公約比較を行う、React + TypeScript + Viteの試作品です。対象地域は沖縄県のみです。メインカラーは `#18345C`。PCは上部ナビ、スマートフォンは下部タブです。

## 開発環境のセットアップ

### 必要なもの

- Node.js 24 LTS推奨（20系は20.19以上、22系以降は22.12以上）
- npm
- Git

### 初回セットアップ

リポジトリをまだ取得していない場合:

```sh
git clone https://github.com/jphacks/ok_2603.git
cd ok_2603
```

既に取得済みの場合は、変更をコミットまたは退避してから、mainの最新状態を取り込みます。

```sh
git switch main
git pull --ff-only origin main
```

Node.jsは事前に各自のPCへインストールしてください。`git pull` はコードを取得する操作で、Node.jsやnpmパッケージのインストール、アプリの起動は行いません。

依存パッケージをロックファイルどおりにインストールし、開発サーバーを起動します。

```sh
npm ci
npm run dev
```

ターミナルのURL（通常 `http://localhost:5173/`）を開きます。既にそのポートが使用中の場合は表示された別ポートを使用してください。終了はCtrl+Cです。
この静的な画面だけを動かす場合、APIキー・ログイン・環境変数・データベースは不要です。外部フォントや画像素材の取得も行いません。

### 沖縄県の選挙情報API

公式サイトから選挙、候補者、選挙公報を収集するNode.js APIを追加しました。利用する場合は `.env.example` を `.env` にコピーし、`ADMIN_API_TOKEN` を設定してから、別のターミナルで `npm run dev:api` を起動します。APIは既定で `http://127.0.0.1:8787` に待ち受けます。Viteの `/api` プロキシからもアクセスできます。収集方法、Gemini無料枠の設定、写真の公開条件、エンドポイントは[選挙情報APIの説明](docs/election-api.md)を参照してください。

現在の画面は既存のレイアウトと静的データを使用します。APIで収集したデータを画面へ接続する変更は含めていません。

### 投票所検索・管理（Supabase）

「投票所を探す」から選挙・市町村ごとに期日前投票所と当日の指定投票所を確認できます。管理画面は既存の管理者トークン認証を使い、施設・投票区・選挙別の期間・時間・公開状態を編集します。地図にはLeafletとOpenStreetMapを使用します。

利用にはSupabaseへのSQLマイグレーション適用とNode.js APIの接続設定が必要です。Supabaseキーはサーバーにだけ設定してください。適用・同期・検証の手順は[投票所管理の説明](docs/polling-places.md)を参照してください。実在する投票所の初期データは含めていません。

## 確認とビルド

```sh
npm test
npm run build
npm run preview
```

`build` はデータ検証、TypeScriptの型チェック、本番バンドル生成を行います。成果物は `dist/` です。`preview` はローカル確認用です。

ローカルのEdge/ChromeでUIテストを実行する場合（Node.js 22以降）:

```sh
node scripts/browser-smoke.mjs
```

開発サーバーを先に起動してください。既定URLは `http://127.0.0.1:5173` です。別URLは `TEST_ORIGIN`、ブラウザー実行ファイルは `TEST_BROWSER` 環境変数で指定できます。テストは一時プロファイルで実行し、テスト用データはそのブラウザーのメモリーにだけ挿入します。公開データには追加しません。画面画像はOSの一時ディレクトリへ保存します。

## 操作と実装範囲

1. 初回の操作ガイドを進める（完了状態はlocalStorageに保存）。「用語」から再表示できます。
2. 沖縄県を選択。市町村別の選挙情報は、公式資料を確認・登録した地域から表示。
3. 地域ページで現在・過去／国政・地方の選挙を切り替え、年代別投票率の数値一覧を確認。
4. 市町村ページの「投票場所」で「期日前投票」「当日投票」を切り替える。期日前投票では、提供された過去資料の場所を確認し、施設名からGoogle Mapsを検索。当日投票は宜野湾市の提供情報（対象選挙・年度と最新性は未確認）を表示し、それ以外の市町村は未収録として表示。
5. 「候補者一覧の収録状況を見る」から候補者一覧へ。氏名・政党・公約の検索に対応。
6. データ登録前は「詳細・具体性チェックを見る」から空状態の詳細5タブと5項目を確認。
7. 「公約比較」→「未収録の比較表示を見る」で横スクロールと表示枠の追加・削除を確認。

登録後の候補者カードは「比較に追加」、詳細、出典の表示に対応します。比較人数に上限はありません。検索結果は候補者単位で公約を表示します。政治用語は確認済みの解説が登録されると公約内でポップアップ表示されます。

**現在、沖縄県内の選挙・候補者・投票率・政治用語の確認済みデータは未収録です。** 実在人物や数値は捏造していません。空状態の表示枠は候補者ではなく、推薦・採点・順位付けもしません。実データを使った閲覧・比較には、公式資料の確認と登録が必要です。

期日前投票所一覧は2026年9月13日執行の選挙に関する過去資料です。現在の投票所や営業状況を示すものではなく、最寄り順や距離は計算しません。地図検索リンクを開くと、選択した市町村名と施設名がGoogle Mapsへ送られます。
