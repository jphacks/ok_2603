# 選挙情報Webアプリ 試作品の仕様

本書は今回ユーザーが提示した確定仕様を実装に対応付ける。既存のFocus Town資料は別企画として保存し、本試作品の要件には適用しない。

## 確定仕様と実装

| 項目                                 | 実装                                                                        |
| ------------------------------------ | --------------------------------------------------------------------------- |
| 名称未定、ネイビー、モダン・シンプル | 選挙情報（仮称）、#18345C                                                   |
| PC上部・スマホ下部ナビ、レスポンシブ | 600px以下で下部タブ、横スクロール領域以外は幅内に配置                       |
| 沖縄県のみ                           | 沖縄県の選択と、沖縄県に対象を限定した選挙データの表示                       |
| 国政・地方／現在・過去               | 登録データのlevel・periodで切り替え                                         |
| 初回チュートリアル                   | 順番に3ステップ、localStorage完了保存、再表示・保存不可の通知               |
| 年代別投票率                         | 選挙ごとの数値テーブル。未登録時は未収録                                    |
| 候補者カード                         | 写真・氏名・所属・公約・出典・詳細・比較に追加                              |
| フリーワード検索                     | 公約・氏名・政党を横断し候補者単位にグループ化。空白区切りAND、全半角正規化 |
| 詳細5タブ                            | 公約／公式経歴／発言／議案への賛否／過去の公約と実施状況                    |
| 公約比較                             | 同じ項目を横並び。人数上限なし、追加・解除、横スクロール                    |
| 具体性5項目                          | 記載状況、根拠文章、出典。独自採点はしない                                  |
| 用語解説                             | 登録済み用語に下線、クリックで解説と出典を開閉                              |
| 情報の区別                           | 未収録／確認できず／該当記録なし。後2つには確認範囲と出典を要求             |

対象地域は沖縄県のみ。沖縄県以外の都道府県は検索・登録・表示の対象外とする。県内41市町村を検索し、入力中に一致する市町村候補を表示する。存在しない名前や候補未選択の入力では検索を無効にし、選んだ市町村の地域ページへ遷移できる。選挙データは沖縄県の有権者に関係する情報に限って収録し、全国の選挙区や住所から投票対象を判定する機能は作成していない。市町村を選択できても、その地域の選挙データが収録済みとは限らない。

市町村ページの「投票場所」には「期日前投票」「当日投票」の切り替えを設ける。初期表示は期日前投票とし、提供された「期日前投票所一覧表」（2026年9月13日執行の選挙、2026年9月4日時点）に掲載された場所を表示する。これは過去の資料であり、現在の投票所を示さない。当日投票所は宜野湾市について利用者提供の4施設と所在地を表示する。対象選挙・年度と最新性は未確認であることを明示し、他市町村は未収録と表示する。当日投票所の地図検索は施設名と所在地を使用する。期日前投票資料に住所・座標がないため距離順や地図ピンは実装せず、施設名によるGoogle Maps検索リンクを提供する。リンクを開く操作では、市町村名と施設名（住所がある場合は住所も）がGoogle Mapsへ送信される。

## データがない場合の操作経路

地域選択 → 市町村ページ（直近の選挙情報が未収録の場合は明示）→ 候補者一覧（未収録）→ 詳細の空状態表示例 → 5タブ・具体性5項目。

公約比較 → 未収録の比較表示 → 表示枠の追加・削除・横スクロール。

表示例は実在候補者でも架空候補者でもなく、未入力のUI枠である。比較対象の選択数には加えない。実在候補者での閲覧・比較は公式資料の確認・登録まで利用できない。

## 未実装と未決定事項

- 実際の選挙、候補者、公約、経歴、議会記録、投票率、用語解説の登録：人が確認した公式資料が提供・登録されていないため、未収録。
- 管理者画面の本格実装・認証・公開承認フロー・DB：未決定。仮の認証方式や自動公開は導入しない。
- デプロイ先・公開方法：未決定。Sites等への公開も行わない。
- 正式アプリ名：未決定。
- 初回登録する地域・選挙・公式資料の範囲と確認担当者：未決定。
- 「現在の選挙」に含める期間や更新頻度：未決定。試作品では確認担当者がperiodを明示し、自動的な日付判定はしない。
- 年代区分：公式資料の区分をそのまま登録できる。全国一律区分への変換や推計は未実装。
- 管理画面とファイル編集の変更競合・取り込み方法・公開責任：DBと公開承認フロー確定後に設計。
- 写真利用許諾・転載範囲・資料更新時の再確認運用：実データ登録前に確認が必要。

市町村ページの直近選挙概要は、公式選挙データが登録されていない場合は未収録と表示する。AI要約の生成機能は未実装であり、情報を自動生成しない。

比較の選択はメモリー内のみ。再読み込み時の復元やログイン同期は要求されていないため導入していない。チュートリアル完了のみ保存する。利用者の候補者検索や比較内容を外部送信しない。

## 技術構成と継続作業

既存React 18 / TypeScript / Vite / npmを維持。依存追加なし。ルーティングライブラリ・管理用サービスは追加していない。画面内状態切り替えで実装し、URL共有・ブラウザー戻るによる画面履歴は未実装。

まず確認済みデータをdata.tsに登録し、検証とレビューを通す。次に管理者認証・公開フロー・DB・公開先を決めて管理機能へ進む。後から型を管理画面の入出力に共有できる構成にしている。
