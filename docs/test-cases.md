# 旧企画資料: Focus Town 初版テスト項目

> この資料は旧企画（学習タイマーと街づくり）のものです。現在の企画・仕様は [沖縄の選挙公約を公式情報で比較するアプリ](election-app-spec.md) を参照してください。

重要度:

- P0: 初版の完了に必要
- P1: 余裕があれば確認

## P0

### タイマー

- [ ] 初期状態で作業タイマーが25分、休憩タイマーが5分と表示される
- [ ] 作業開始ボタンで25分の計測が始まる
- [ ] 一時停止後、残り時間が保持される
- [ ] 再開後、保持した残り時間から計測が続く
- [ ] 作業完了時に完了処理が1回だけ実行される
- [ ] 作業完了後、5分休憩は利用者が開始した場合のみ始まる
- [ ] 休憩完了後、次の作業は自動で始まらない

### 画面非表示と中断

- [ ] 作業中に別タブへ移るとタイマーが一時停止する
- [ ] 元のタブへ戻ってもタイマーが自動再開しない
- [ ] 再開ボタンから残り時間を続けられる
- [ ] 中断時に一時停止中・残り時間・手動再開方法が表示される
- [ ] 中断時に街が利用者の帰りを待つ、非罰的な演出が表示される
- [ ] 中断演出で累計セッション数、街の成長、残り時間が減らない
- [ ] 休憩中に画面を非表示にしても作業用の中断演出が起きない
- [ ] 街の破壊や利用者への罰と受け取られる演出・文言がない
- [ ] 中断を不正や失敗と決めつける表示がない

### 街と住民のメッセージ

- [ ] 作業を完了すると累計完了セッション数が1増える
- [ ] 作業を完了すると街の成長が更新される
- [ ] 完了時に住民の固定メッセージが表示される
- [ ] 一時停止やページの再描画でセッション数が重複加算されない
- [ ] 成長段階の節目（初期案: 1回、4回、8回）に応じた街が表示される

### 保存とプライバシー

- [ ] 再読み込み後も累計セッション数と街の成長が保持される
- [ ] カメラ、マイク、位置情報の許可を要求しない
- [ ] ログインを要求しない
- [ ] 外部AI APIへデータを送信しない
- [ ] ブラウザー保存データがない場合に初期状態から利用できる

### 画面操作

- [ ] スマートフォン幅で主要操作と街が表示される
- [ ] PC幅で主要操作と街が表示される
- [ ] タッチとキーボードで主要ボタンを操作できる
- [ ] タイマーの状態と残り時間が読み上げ可能な形で提供される

### 一連のデモ動作

- [ ] ブラウザーを開いてから、作業開始・一時停止と再開・完了・街の成長・住民メッセージまで一連の操作を実演できる
- [ ] 作業中にページを非表示にした際の一時停止を実演でき、戻った後は手動再開となる
- [ ] 完了後に再読み込みし、保存した街の成長が復元される
- [ ] デモに必要なファイルや機能が欠けず、発表で使うブラウザーと画面サイズで動作する
- [ ] 短縮タイマーを使う場合、開発時だけ有効であり、本番ビルドでは作業25分・休憩5分になる

### 問題・解決策の検証

- [ ] 対象者に最近の中断経験と再開時の困りごとを尋ね、想定課題が実際にあるか確認する
- [ ] 対象者が説明なしで「完了した作業が街に残る」ことと中断後の再開方法を理解できる
- [ ] 中断演出が罰や街の損失と誤解されない。誤解された場合は表現を修正する
- [ ] 既存のタイマーや習慣化手段と比較し、使いたい／使わない理由を記録する
- [ ] 少人数の感想を効果の証明として表現せず、観察範囲と未検証点を区別する

## P1

- [ ] OSの「視差効果を減らす」設定に配慮して演出を抑えられる
- [ ] ブラウザーを再読み込みしても、意図しない作業時間の加算が起きない
- [ ] 不正な保存データがあっても画面がクラッシュしない
- [ ] 成長段階のしきい値を変えても既存の完了数から正しい段階が表示される

## 手動確認

タイマーの25分・5分すべてを待たず、実装時はテスト用の短い時間設定またはタイマー計算の単体テストで完了処理を確認する。短縮設定は本番ビルドで有効にならないことを確認する。発表前の通し確認には [デモ・発表計画](demo-plan.md) を使う。

審査基準との自己点検には [JPHACKS 2026審査基準との対応](jphacks-rubric.md) を使う。自己採点は審査結果の予測ではなく、根拠の不足を見つけるためのチーム内レビューである。
